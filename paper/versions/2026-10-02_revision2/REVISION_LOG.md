# Revision 2 changes and story chain

基准为 `d52d480` 的双稿初稿；新稿保存在独立目录。academic-research-suite 的修订与证据一致性流程用于限定改写范围、保留方法版本并逐项回应审阅；PDF 技能用于最终渲染检查。没有由 skill 引入新的审批链。

| 审阅问题 | 本轮完成的修改 | 依据 |
|---|---|---|
| legacy/canonical 差异未量化 | 实际重算 74,750 条预测；两稿替换“尚未核查”为真实影响 | 双评分 CSV、逐题旧值与原区间重建 |
| yes/no 与空归一化规则混淆 | 分别描述 HotpotQA 与 MuSiQue、aliases 独立取最大值 | 固定官方源码、定向差分测试 |
| 位置比较被不必要地弱化 | 恢复固定可见证据的 ordering/placement-policy 表述 | 全部 2,500 query / 5,000 prompt 实际重建 |
| 条目预算与 token 上限混同 | 新增 token 分布表、明确零截断及列表置换 | 逐题可见内容检查及全范围 prompt audit 统计 |
| 理论与历史算法不对应 | 会议稿紧致度证明移至附录；期刊稿扩展路径依赖反例移至附录 | 原历史算法定义保持；v2 不进入结果 |
| 标准覆盖界被误当新贡献 | 明确为背景代理目标性质，不能推出 HGRAG F1 保证 | 期刊理论节与贡献段 |
| 数字与图表需统一 | 两稿共用 canonical 数字宏和重新派生的两张 forest plot | 17 个 effect rows 与真实重算输出对应 |
| 成本范围混淆 | 区分 checkpoint 累计秒数、事务调用数和最后进程调用数 | 已有 runner 与冻结 telemetry，不重新计时 |
| 缺少复现细节 | 补充 encoder/pooling/query instruction、切句、BM25/hybrid、prompt 与解码 | 所读历史代码段与配置 |
| PDF 需真实验收 | 两稿编译并逐页查看全部最终 30 页 | 实际日志、PNG、每页记录 |

中文故事链：多跳答案需要互补证据，但 Top-20 条目有限 → 结构补全在紧凑 MiniLM 主干上重复改善答案 → 组件对照支持特定 facet selector，但没有证明粒球不可替代 → 换成强 BGE 后，原系统更差，两个增强方案的增量不确定 → 同一可见证据集合的放置顺序仍可影响答案，protected 优于直接前置 → 因此论文贡献是有明确适用条件的 evidence-completion 方法及受控经验发现，不是普遍强检索优势。

会议版用 9 页突出主线、主要比较及关键边界；期刊版用 21 页展开历史方法、直接适用的理论、已有案例、证据置换、成本和位置核查。期刊版没有新增正式实验，两版不是两项独立实证贡献。

未改变：历史预测、Gold、rankings、方法配置、C10、旧统计方案与历史决策。未补齐但继续披露：结构必要性/普通聚类与 MMR 匹配对照、强主干增量、开放域及外部结构系统公平比较。任何此类实验需要另行明确授权。
