# Data availability

Sources: [HotpotQA](https://hotpotqa.github.io/) and [MuSiQue](https://github.com/StonyBrookNLP/musique). The study uses existing exposed cohorts, not the complete official datasets or a new confirmation split.

The public numerical supplement contains de-identified saved score observations, paired changes, selected-score bins, development-role counts, existing timing/training summaries, and a Python standard-library reconstruction script. It does not rescore answers and cannot independently regenerate model predictions.

Exact questions, answers, source identities, original text, cohort mappings, personal submission data, and trained weights are excluded. The user intends code and lawful derived-data release; this task releases the allowed numeric subset only. Broader redistribution requires source-license and author review. No model-weight release is promised. Full experiments additionally require original cohort manifests, authorized source mappings, models, checkpoints, and research environments.

Missing saved per-query Dense-K6 logits/reference sets and refined-subset raw timings remain unavailable; no inference was used to reconstruct them.
