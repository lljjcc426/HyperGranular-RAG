## 直接证据

- Fixed TF-IDF: ALL CR@10 = 0.3125, ER@10 = 0.6187。
- Boundary fallback: ALL CR@10 = 0.3200，接近 TF-IDF，但 fallback_rate = 0.9175，说明收益主要来自边界回退策略。
- Unsupervised hyperedge: ALL CR@10 = 0.3700，ER@10 = 0.6410，但 false_expansion_rate = 0.9456，噪声很高。
- Query-aware hyperedge: ALL CR@10 = 0.3225，未明显超过无监督超边，说明仅靠 query-aware 重排不足。
- Facet-aware hyperedge: ALL CR@10 = 0.3725，MuSiQue CR@10 = 0.4150，false_expansion_rate = 0.8560，是当前较稳的机制证据。
- Facet-aware larger budget: ALL CR@5 = 0.2000，ER@5 = 0.4874，但 CR@10 = 0.3600，较 e2/b2 配置稍低。

## 当前结论边界

- 可支持的说法：Facet-aware 超边在多跳链路召回上优于固定句子 TF-IDF，尤其 MuSiQue 的 CR@10 从 0.2950 到 0.4150。
- 不能支持的说法：粒球本身天然优于 fixed chunk；Stage1 中 naive granular ball 的 ALL CR@10 只有 0.2950。
- 仍需解决：超边扩展的 false_expansion_rate 仍高于 0.85，下一步应定位改进/退化样例，而不是继续盲目加预算。
