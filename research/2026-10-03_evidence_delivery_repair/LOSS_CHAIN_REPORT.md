# 原 static-q25 的证据损失链（已开放历史材料）

本报告是探索性、描述性诊断，不是新独立确认或因果中介分析。
MiniLM 缓存逐行 unit/query ID 对应通过；Dense、q25最终排名及插入列表
逐题与归档一致：HotpotQA 1,000/1,000，MuSiQue 3,000/3,000。
未改变原分球、词面门、分数、q25或历史输出。

## 两条路径分别计数

| 注释粒度与计数 | HotpotQA：支持句 | MuSiQue：支持段落 |
|---|---:|---:|
| 标注支持目标总数 | 2,384 | 7,039 |
| 原 Dense20 已覆盖 | 2,083 | 5,565 |
| 原 Dense20 缺失、候选中存在 | 301 | 1,474 |
| 缺失目标经 H0 扩展送达 | 84 | 347 |
| 缺失目标在球级提案阶段被排除 | 173 | 988 |
| 已进入入选球，但 q25 排除 | 27 | 107 |
| 通过 q25，但插入容量/句子选择未取出 | 17 | 32 |
| 原 Dense 已有支持因最终替换丢失 | 13 | 77 |
| H0 最终覆盖 | 2,154 | 5,835 |
| 原 prompt-visible 覆盖 | 2,154 | 5,835 |

前四类缺失目标去向相加分别为301和1,474。球级损失占原 Dense 缺失目标的
57.5%和67.0%；局部 R1 能直接触及的“已入球、过 floor、未取出”仅17和32。
入选球已有但最终没有送达的目标总数为44和139，包含 floor 与容量两类；
R1/R2 没有权限恢复 floor 之下的候选。

MuSiQue 的一个支持段落可以由多句候选代表：一个目标只计一次，以其候选
成员中达到最远步骤者确定分阶段去向。逐句去向也保留，不能解释为标注指定了
某个唯一正确事实句。上述“球级排除”是该扩展支路未通过，并不意味着原 Dense
fill 会删除这些球里的所有句子。已经在 Dense 的目标用另一条保留/移除路径计数。

| 扩展支路中首个未通过的条件 | HotpotQA 缺失支持句 | MuSiQue 缺失支持段落 |
|---|---:|---:|
| seed 排除 | 37 | 58 |
| 相对 seeds 无足够新问题词项 | 77 | 477 |
| 球过大 | 2 | 82 |
| relevance/seed anchor 门 | 0 | 9 |
| units per new term | 5 | 37 |
| redundancy 门 | 1 | 0 |
| facet score 门 | 16 | 47 |
| 通过门但未进入两条 edge 预算 | 35 | 278 |

无新问题词项不是“没有桥接信息”的语义判定。现有数据能定位词面门遗漏，
不能仅据这一条件把遗漏句命名为桥接关系。标注支持不是全部合法证据的全集。

## 球承诺、句子兑现和完整上下文不同

| 诊断量 | HotpotQA | MuSiQue |
|---|---:|---:|

| 声称新 facet 在完整最终列表仍有缺失的球 | 101 | 834 |

| seed union 与真实保护前缀 union 不同的 query | 556/1,000 | 2,069/3,000 |
| Dense20 覆盖候选中全部可观察问题词项 | 704/1,000 | 1,023/3,000 |
| prefix 覆盖问题全部有效词项 | 194/1,000 | 129/3,000 |
| Dense20 覆盖问题全部有效词项 | 308/1,000 | 274/3,000 |
| 完整候选覆盖问题全部有效词项 | 448/1,000 | 754/3,000 |

第一种 phantom 比例不能直接当完整 prompt 的信息损失比例：Dense fill 可以
提供那些词项，故两行566→101、2,277→834必须分开。词面覆盖饱和不等于
推理链充分；Phi 没有蕴含、别名或隐含桥梁识别能力。

原代码已核实：min_size2/max_size3 下 radius 门不独立决定 split；候选球相对
seeds 一次评分；选第二球时不重算其真实边际；球内句子 bonus 权重为0。
这些行为全部保留，未用本轮修复解释历史成绩。

## 机器可读追溯与解释范围

公开：`LOSS_SUMMARY.json`、`DELIVERY_FACETS_SUMMARY.json` 和固定采样/排名文件。
本地可再生逐题记录：`local/loss_queries.jsonl` 包含支持目标及各成员的排除原因、
分球门、选择球、phantom、Dense保留路径和旧答案 gain/same/harm；
`local/delivery_facets.jsonl` 逐题区分 prefix/Dense/inserted/final/visible 的 ID、
title/body/union facets。前者含 Gold 派生逐题标注，不上传 Git。
`LOSS_SUMMARY.json` 中交叉表以历史 canonical 答案变化分组，只作描述。

这次诊断说明存在接口损失，但多数可恢复支持在本轮局部修复之前已经被排除。
R1 是否改善答案、R2 是否值得选择不同 eviction，须由固定400题比较回答，
不能从本报告的可恢复数量直接推导。
