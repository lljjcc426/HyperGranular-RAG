# Bounded method-section check

Read on 2026-10-04: the method sections identified below, not a claimed full-corpus literature review. No external method deployed. No external scores pooled with this experiment.

| Work / status / primary source | Actual method inspected | Overlap and v5 difference |
|---|---|---|
| [RECOMP, ICLR2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/bda88ed2892f5e61c9a9bf215c566913-Paper-Conference.pdf), §§2–3.1 | Extractive sentence dual encoder trained with downstream LM utility; separate abstractive distillation; selective augmentation | Learned context selection is prior work. v5 uses known-support paragraph-set supervision, no answer-likelihood teacher calls, no generated summary. |
| [SetR, ACL2025](https://aclanthology.org/2025.acl-long.861.pdf), §3 | Information-requirement CoT and set-wise selection; 40K GPT-4o-labeled top20 sets distill Llama3.1-8B | Joint completeness/conciseness is not new. v5's small frozen-embedding model differs; DeepSets is not a SetR reproduction. |
| [Beam Retrieval, NAACL2024](https://aclanthology.org/2024.naacl-long.96.pdf), §3.1–3.2 | Concatenated query/passage chain encoder, first/subsequent-hop heads; multiple hypotheses | Beam passage selection is prior work. v5 scores unordered annotation-conditioned sets with cached factors; neither beam establishes global optimality. |
| [Cross-Granularity Hypergraph RAG, AAAI2026](https://ojs.aaai.org/index.php/AAAI/article/view/40623/44584), Methodology / construction / retrieval | LLM-extracted entity nodes, passage hyperedges, entity/passage similarity diffusion and enhancement | Shared passages and higher-order language already exist. v5 does not extract entities or use incidence diffusion; factors are interactions, not factual relations. Full title avoids HGRAG acronym collision. |
| [HyperReCo, arXiv v1](https://arxiv.org/html/2609.32327v1), §§3–4.2 | Entity/document hypergraph, query-conditioned HyperGNN, document/entity supervision; gradient-guided paths and query-PCSF | Supervised query-dependent higher-order evidence retrieval is covered. v5 tests explicit low-rank set scores and exact conditional search, not message passing/path decoding. Only preprint status verified. |
| [SGBGC, AAAI2025](https://ojs.aaai.org/index.php/AAAI/article/view/33404/35559), definitions and coarse/fine splitting | Label-purity splitting, graph shortest-path centers and supernode graph coarsening for GNN training | Supervised granular balls are not new. v5 preserves each raw member and indexes learned factors; it neither coarsens the graph nor uses evaluation labels in splitting. |
| [HOFM](https://arxiv.org/html/1607.07195), §§2–3 | Low-rank distinct-feature ANOVA interactions and differentiable dynamic programming | Direct algebraic ancestor. No new hypergraph theorem claimed. v5 makes factors/query weights conditional on frozen text and supervises evidence sets. |
| [Maximum Inner-Product Search using Tree Data-structures](https://arxiv.org/html/1202.6101), §3, Theorem3.1 | Farthest-pivot ball tree and center-plus-radius inner-product upper bound | Direct search ancestor. v5 changes the conditional scoring space and feasibility filter; ball bound itself is standard. |

Mentor view: test the learned objective against H1/H2/DeepSets before investing in structure. Reviewer view: any gain shared by H1 is supervised selection, any efficiency shared by KM is indexing, not granular-ball exclusivity. Exact search equality is correctness; only measured end-to-end cost can support practical value. The candidate contribution is their combination under this task boundary, contingent on results, not established novelty.
